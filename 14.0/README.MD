# Soma dos Elementos de um Vetor
---
> Descrição:

Faça um programa em C que leia um número inteiro `N (1 ≤ N ≤ 10)`, representando a quantidade de elementos de um vetor.
Em seguida, leia N números inteiros e armazene-os no vetor.

Utilize ponteiros para percorrer o vetor e calcular a soma de todos os seus elementos.

---

> Entrada:

Um número inteiro `N`, seguido de `N` números inteiros.

---

> Saída:

Imprima a soma dos valores armazenados no vetor.

---

Exemplo de entrada:

```c

5
1 2 3 4 5


```

Exemplo de saída:

```c
15

```
