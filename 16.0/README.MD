# Contagem de Valores Positivos em um Vetor
---
> Descrição:

Faça um programa em C que leia cinco números inteiros e os armazene em um vetor.
Utilize ponteiros para percorrer o vetor e contar quantos dos valores lidos são positivos (maiores que zero).

---

> Entrada:

Cinco números inteiros.

---

> Saída:

Imprima a quantidade de valores positivos encontrados.

---

Exemplo de entrada:

```c

-2 4 0 7 -1



```

Exemplo de saída:

```c
2

```
