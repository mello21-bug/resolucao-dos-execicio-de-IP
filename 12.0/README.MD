# Maior Valor Utilizando Ponteiros
---
> Descrição:

Construa um programa em C que leia dois números inteiros e armazene-os em variáveis distintas.
Crie ponteiros para acessar essas variáveis e, por meio deles, determine qual dos dois valores é o maior.

---

> Entrada:

Dois números inteiros.

---

> Saída:

Imprima o maior valor entre os dois números lidos.

---

Exemplo de entrada:

```c

8 2

```

Exemplo de saída:

```c
8

```
