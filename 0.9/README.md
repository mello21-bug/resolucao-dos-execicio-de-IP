# Dobro por Referência

---
> Descrição:

Desenvolva um programa em C que leia um número inteiro e armazene esse valor em uma variável.
Crie um ponteiro que aponte para essa variável e utilize-o para calcular o dobro do valor informado.

O cálculo do dobro deve ser feito usando o conteúdo apontado pelo ponteiro.
---

> Entrada:

Um número inteiro.

---

> Saída:

Imprima o dobro do valor lido.

---

Exemplo de entrada:

```c

5

```

Exemplo de saída:

```c
10

```
