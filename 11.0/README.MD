# Troca de Valores por Referência

---
> Descrição:

Escreva um programa em C que leia dois números inteiros `A` e `B`.
Utilize ponteiros para trocar os valores armazenados nessas variáveis, de forma que o valor de `A` passe para `B` e o valor de `B` passe para `A`.

A troca deve ser realizada exclusivamente utilizando ponteiros.

---

> Entrada:

Dois números inteiros `A` e `B`.

---

> Saída:

Imprima os valores de `A` e `B` após a troca, separados por um espaço.

---

Exemplo de entrada:

```c

3 9

```

Exemplo de saída:

```c
9 3

```
