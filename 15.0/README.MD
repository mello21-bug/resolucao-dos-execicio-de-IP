# Metade de um Valor Real por Referência
---
> Descrição:

Desenvolva um programa em C que leia um número real e armazene esse valor em uma variável.
Crie um ponteiro para acessar essa variável e utilize-o para calcular e imprimir a metade do valor informado.

O resultado deve ser exibido com duas casas decimais.

---

> Entrada:

Um número real.

---

> Saída:

Imprima a metade do valor com duas casas decimais.

---

Exemplo de entrada:

```c

6.5


```

Exemplo de saída:

```c
3.25

```
