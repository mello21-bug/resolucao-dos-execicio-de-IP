# Soma de Dois Valores com Ponteiros

---
> Descrição:

Faça um programa em C que leia dois números inteiros e armazene cada um deles em uma variável distinta.
Crie ponteiros para acessar essas variáveis e utilize apenas os ponteiros para calcular a soma dos dois valores.

---

> Entrada:

Dois números inteiros.

---

> Saída:

Imprima a soma dos valores lidos.

---

Exemplo de entrada:

```c

4 7

```

Exemplo de saída:

```c
11

```
