# Valor Apontado

---
> Descrição:

Escreva um programa em C que leia um número inteiro informado pelo usuário.
O valor lido deve ser armazenado em uma variável inteira. Em seguida, o programa deve criar um ponteiro que aponte para essa variável e utilizá-lo para acessar o valor armazenado.

O valor deve ser impresso exclusivamente por meio do ponteiro, não sendo permitido o acesso direto à variável.
---

> Entrada:

Um único número inteiro.

---

> Saída:

Imprima o valor armazenado na variável, acessado através do ponteiro.

---

Exemplo de entrada:

```c

6

```

Exemplo de saída:

```c
6
```
