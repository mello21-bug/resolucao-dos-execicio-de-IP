# Resolução dos Exercícios de Introdução à Programação (IP)

Este repositório contém as soluções desenvolvidas para os exercícios e listas de atividades da disciplina de Introdução à Programação (IP). O objetivo principal é documentar o aprendizado de lógica de programação e algoritmos, servindo como material de consulta e estudo.

---

># Sobre o Projeto
O repositório está organizado por tópicos ou listas de exercícios, cobrindo desde os conceitos básicos de sintaxe até estruturas mais complexas. As resoluções buscam aplicar boas práticas de programação e clareza no desenvolvimento da lógica.

---

># Estrutura do Repositório
O conteúdo está dividido em pastas ou arquivos que seguem a progressão da disciplina:

>Conceitos Básicos: Variáveis, tipos de dados e operadores.

>Estruturas de Controle: Condicionais (if/else, switch) e estruturas de repetição (for, while).

>Funções e Procedimentos: Modularização de código e passagem de parâmetros.

>Vetores e Matrizes: Manipulação de estruturas de dados homogêneas.

>Projetos/Desafios: Problemas mais complexos que integram diversos conceitos.

># Tecnologias Utilizadas

Linguagem: C

Ferramentas: VSCode
